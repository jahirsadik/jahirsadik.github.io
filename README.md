# jahirsadik.github.io

Personal academic website, built with [al-folio](https://github.com/alshedivat/al-folio) (v0.16.3) and deployed to GitHub Pages.

- Source lives on `master`. Pushing to `master` runs `.github/workflows/deploy.yml`, which builds the site and pushes the result to the `gh-pages` branch (do not edit `gh-pages` by hand).
- Content: `_pages/` (about, publications, teaching, …), `_bibliography/papers.bib` (publications; put preview GIFs in `assets/img/publication_preview/`), `_news/` (front-page news), `_posts/` (presentations & blogs), `_projects/` (activities), `_teachings/` (teaching).
- The previous academicpages version of the site is preserved on the `academicpages-archive` branch.
- Customisation notes: `CUSTOMIZE.md`, `FAQ.md`, `INSTALL.md`.
